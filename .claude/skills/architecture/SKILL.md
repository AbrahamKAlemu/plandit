# Architecture

Read the brief and relevant existing code before design. Use the [templates](../feature-forge/references/templates.md). Preserve reconnaissance, affected components, data/state contracts, flows, failures, trust boundaries and meaningful alternatives with rationale. Reference requirements and the Plan verification table instead of duplicating them. Select independent architecture/security perspectives by need and back-patch contradictions. Skip wireframes; Plan follows.
